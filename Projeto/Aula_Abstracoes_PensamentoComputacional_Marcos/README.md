# 🧩 udfilaSystem

O **udfilaSystem** é um projeto voltado para o gerenciamento de filas e controle de acesso de usuários em ambientes institucionais.  
Seu objetivo é otimizar o fluxo de atendimento e cadastro, garantindo que cada usuário tenha acesso conforme seu perfil (Aluno, Atendente ou Administrador).

---

## 🎯 Objetivo do Projeto

O sistema busca oferecer uma solução eficiente para:
- Gerenciar filas de atendimento.
- Controlar o acesso de usuários por perfil.
- Automatizar o processo de cadastro e autenticação.

A parte apresentada neste repositório — **fluxograma e pseudocódigo** — representa **a abstração do processo de cadastro de usuário**, uma das etapas fundamentais do sistema.

---

## 🧠 Abstração Utilizada

A abstração modela o **fluxo de interação do usuário** desde o primeiro contato com o sistema até a criação da conta.  
Ela simplifica o comportamento do sistema em etapas lógicas e decisórias, permitindo visualizar o processo antes da implementação.

Etapas principais:
1. **Página Inicial** — opções de *Login* ou *Cadastrar-se*.  
2. **Formulário de Cadastro** — coleta de dados institucionais.  
3. **Validação de Perfil e Senha** — garante acesso apenas a perfis autorizados.  
4. **Criação da Conta** — confirma o sucesso ou exibe mensagens de erro.

---

## 🧩 Componentes

- **Fluxograma:** Representa graficamente o processo de cadastro e suas decisões.  
- **Pseudocódigo:** Traduz o fluxo em lógica estruturada (Portugol), simulando o comportamento do sistema.

---

## 💻 Tecnologias e Conceitos

- Modelagem de processos (fluxogramas)
- Lógica de programação (condicionais e validações)
- Abstração de interação humano-sistema
- Estrutura modular para integração futura com o sistema principal **udfilaSystem**
