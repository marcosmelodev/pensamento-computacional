#  Aula Organização de Dados
 
## Descrição da Atividade
 
Esta atividade tem como objetivo representar a estrutura de um projeto de software real — o **udfilasystem-backend** — utilizando três diferentes formas de organização de dados:
 
1. **Lista** (`Lista.md`): Representação textual hierárquica com indentação, listando todos os arquivos e diretórios do projeto.
2. **Hierarquia** (`Hierarquia.png`): Organograma visual que mostra a relação pai-filho entre os módulos e diretórios do projeto.
3. **Grafo** (`Grafo.png`): Rede de conexões entre os componentes do sistema, evidenciando as dependências e comunicações entre módulos.
## Projeto Base
 
**Repositório:** [udfilasystem-backend](https://github.com/marcosmelodev/pensamento-computacional/tree/main/Projeto/udfilasystem/udfilasystem-backend)
 
O projeto é um backend para um sistema de gerenciamento de filas universitárias, desenvolvido com Node.js e Express. Ele possui módulos para autenticação de usuários, controle de filas e emissão de tickets/senhas.
 
## Objetivos
 
- Compreender como diferentes estruturas de dados representam a mesma informação de formas distintas.
- Identificar relações hierárquicas (árvore) e relacionais (grafo) em um projeto real.
- Praticar a leitura e interpretação de projetos de software.
