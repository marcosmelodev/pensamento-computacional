
# UDFilaSystem

Sistema desenvolvido para gerenciamento de filas e autenticação de usuários com JWT e autenticação em duas etapas (2FA).

## Tecnologias utilizadas

- Java 21
- Spring Boot
- Spring Security
- JWT
- React/Vite
- Node.js
- MySQL

## Objetivo da atividade

Aplicar técnicas de tratamento de erros e avaliação de soluções diretamente no projeto em desenvolvimento, identificando falhas reais de execução, configuração e integração entre frontend e backend.

## Resultado

Os erros identificados foram corrigidos com sucesso, permitindo a comunicação correta entre frontend e backend, autenticação funcional e inicialização adequada do ambiente de desenvolvimento.
